# Patricia Lucas

Sitio web de Patricia Lucas: oratoria, locución y maestría de ceremonias.

- Sitio estático (index.html + videos y fotos).
- Publicado en Vercel.
- El formulario guarda los mensajes en Supabase, tabla `pl_contactos`.
- Para activar WhatsApp, escribe el número en la variable `WHATSAPP` de index.html.
